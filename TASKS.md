# TASKS.md

This file tracks the MVP development plan for the four-developer Vibe Coding workflow.

## Review Rule

Before merging a PR into `dev`, at least one independent review is required. The reviewer may be another human developer or the designated AI reviewer defined in `AGENTS.md`. A non-blocking designated AI review satisfies the review requirement without any additional human approval.

All other development phases, ownership boundaries, integration milestones, and daily workflow remain governed by the current `AGENTS.md`, `ARCHITECTURE.md`, and `API_CONTRACT.md`.
